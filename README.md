# YAY Keyboard AI

iOS-приложение с AI-ассистентом для ответов клиентам: собственная клавиатура с панелью ассистента, голосовая команда вместо диктовки, варианты делового ответа на иврите (с переводом на русский), быстрые шаблоны и переписывание текста одним касанием.

Сейчас в репозитории только техническое задание (без кода).

**Полное ТЗ:** [docs/SPEC.md](docs/SPEC.md)

Ключевые решения и ограничения iOS описаны в разделах 2 и 3 ТЗ, риски и открытые вопросы - в разделе 13.
